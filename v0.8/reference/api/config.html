Configuration¶

class Config(imports: str | tuple[str, ...]='all', deny_imports: tuple[str, ...]=(), include_private: bool = False, respect_all: bool = True, include_docstrings: bool = False, infer_types: bool = False, incremental: bool = False, resolve_kwargs: bool = True, resolve_args: bool = True, union_style: UnionStyle = UnionStyle.MODERN, alias_style: AliasStyle = AliasStyle.COMPATIBLE, version_branches: VersionBranches = VersionBranches.EMIT, exclude: tuple[str, ...]=('.*', '__pycache__', 'build', 'dist', '.venv', 'venv', '*.egg-info', '.git', '.tox', '.nox', '<non-identifier>'), extend_exclude: tuple[str, ...]=<factory>, output_dir: str | None = None, targets: tuple[str, ...]=<factory>, modules: tuple[str, ...]=<factory>, verbose: bool = False, strict: bool = False, target_python: str = '3.10', docstrings: DocstringTargets = DocstringTargets(packages=(), import_root=None, overrides=()))[source]¶

Bases: object

Options for one stubpy run.

Every field has a default, so Config() is a valid configuration. Instances are immutable; use replace() to derive a changed copy. Enum fields also accept their string values (union_style="legacy").

Parameters:

  • imports (str or sequence of str) – Which modules stubpy may import (execute): "all" (the default), "none" (source analysis only, nothing is executed), "stdlib", or a list of dotted names (pkg or pkg.*, each with its submodules) allowed on top of the standard library. A target whose import is blocked, directly or through one of its imports, is stubbed from its source with an INFO. This limits import-time side effects; it is not a security sandbox.

  • deny_imports (sequence of str) – Dotted names (pkg or pkg.*) never imported, whatever imports allows. Defaults to none.

  • include_private (bool) – Stub names that start with _. Defaults to False.

  • respect_all (bool) – When a module defines __all__, stub only the public names it lists. Defaults to True.

  • include_docstrings (bool) – Use each symbol’s docstring as its stub body instead of .... Defaults to False.

  • infer_types (bool) – Fill in missing parameter and return types from NumPy, Google or Sphinx docstrings. Defaults to False.

  • incremental (bool) – Wrap the generated stub in # stubpy: auto-generated begin/end markers and merge it into an existing .pyi, keeping manual edits outside the markers. Defaults to False.

  • resolve_kwargs (bool) – Expand **kwargs into the parameters it is forwarded to. Defaults to True.

  • resolve_args (bool) – Expand *args into the positional parameters it is forwarded to. Defaults to True.

  • union_style (UnionStyle or str) – "modern" (X | None) or "legacy" (Optional[X]). Defaults to "modern".

  • alias_style (AliasStyle or str) – "compatible" (X: TypeAlias = ...), "pep695" (type X = ...) or "auto". Defaults to "compatible".

  • version_branches (VersionBranches or str) – "emit" copies if sys.version_info ... / if sys.platform ... blocks into the stub with every branch; "resolve" keeps only the branch the running interpreter takes. Defaults to "emit".

  • exclude (sequence of str) – Patterns of files and folders a folder run skips; setting it replaces the defaults (hidden names .*, __pycache__, build, dist, .venv, venv, *.egg-info, .git, .tox, .nox and <non-identifier>, any folder or module name Python cannot import). A pattern with / matches the path relative to the folder target, one without matches any single name. Files named directly are never skipped.

  • extend_exclude (sequence of str) – More patterns, added to exclude.

  • output_dir (str or None) – Stub root used when generate() gets no output; None writes each stub next to its source.

  • targets (sequence of str) – Paths, folders or globs to act on when no target is given.

  • modules (sequence of str) – Dotted module names to act on when no target is given.

  • verbose (bool) – Report INFO diagnostics on the command line. Defaults to False.

  • strict (bool) – Count WARNING diagnostics as failures. Defaults to False.

  • docstrings (DocstringTargets or mapping) – The [tool.stubpy.docstrings] table: the hand-written stubs stubpy docstrings syncs when given no STUB.

  • target_python (str) – Oldest Python ("3.10") the stubs must import on: typing names added later (Self, override, TypeIs, deprecated, …) are imported from typing_extensions. Defaults to "3.10".

Raises:

  • ValueError – If an enum field gets an unknown value.

  • TypeError – If a flag is not a bool or a list field is not a list of strings.

Examples

>>> cfg = Config(imports="none", include_private=True)
>>> cfg.may_import
False
>>> cfg.replace(union_style="legacy").union_style.value
'legacy'

Build a config from a mapping such as a [tool.stubpy] table.

Keys are field names; dashes are read as underscores.

Parameters:

Returns:

class VersionBranches(*values)[source]¶

Bases: _Choice

What happens to if statements testing sys.version_info or sys.platform.

Variables:

  • EMIT – Copy the if / elif / else into the stub, each branch with the stubs of the names it defines, as typeshed does. The default.

  • RESOLVE – Keep only the branch the running interpreter takes.

EMIT = 'emit'¶
RESOLVE = 'resolve'¶

class DocstringTargets(packages: tuple[str, ...] = (), import_root: str | None = None, overrides: tuple[tuple[str, str], ...] = ())[source]¶

Bases: object

The stubs stubpy docstrings acts on when it gets no STUB or -m MODULE.

Variables:

  • packages (tuple of str) – Folders searched for *.pyx files and compiled modules that have a .pyi of the same stem next to them.

  • import_root (str or None) – The folder module names are relative to ("src" for a src layout); None finds it by walking up __init__.py folders.

  • overrides (tuple of (str, str)) – (module, stub path) pairs, from a mapping, for stubs of another name or place; an empty path drops a discovered module.

Examples

>>> DocstringTargets.coerce({"packages": ["mypkg"]}).packages
('mypkg',)
