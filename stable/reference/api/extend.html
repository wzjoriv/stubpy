Annotation handlers¶

register_annotation_handler(predicate: Callable[[Any], bool], *, first: bool = False) → Callable[[Callable[[Any, StubContext], str]], Callable[[Any, StubContext], str]][source]¶

Register a custom annotation-to-string handler.

A handler turns a live annotation object into stub text. By default it runs after every built-in handler, so it only sees annotations none of them matched; first=True puts it ahead of all registered handlers.

Parameters:

  • predicate (callable) – predicate(annotation) -> bool; True for the annotations the handler renders.

  • first (bool, default False) – Try this handler before every other one.

Returns:

callable – A decorator that registers handler(annotation, ctx) -> str and returns it unchanged.

Examples

from stubpy.extend import annotation_to_str, register_annotation_handler

@register_annotation_handler(lambda a: isinstance(a, Validated))
def _validated(annotation, ctx):
    return f"Validated[{annotation_to_str(annotation.inner_type, ctx)}]"
annotation_to_str(annotation: Any, ctx: StubContext) → str[source]¶

Render a live annotation object as stub text.

Empty sentinels give ""; a registered alias wins; then the first matching handler; otherwise str(annotation) without typing., or "" when that is not an expression (an object’s <...> repr).

Examples

>>> from typing import List
>>> annotation_to_str(List[int], StubContext())
'list[int]'

Forwarding resolvers and stub hooks¶

register_forward_resolver(fn: Callable[[str, dict[str, Any]], Any]) → Callable[[str, dict[str, Any]], Any][source]¶

Register fn to name the target of a **kwargs / *args forward, such as one stubpy cannot find.

fn is called as fn(name, namespace) with the call-site text ("draw", "self.backend.draw") and the module’s globals, and returns the callable or class the call forwards to, or None to leave it to stubpy. Resolvers are asked before stubpy’s own lookup, in registration order; the first non-None result wins. They need the module’s live objects, so they are not used with imports="none". Usable as a decorator.

Parameters:

fn (callable) – (name: str, namespace: dict[str, Any]) -> object | None.

Returns:

callable – fn, unchanged.

See also

register_stub_hook

Change the finished stub text.

Examples

>>> @register_forward_resolver
... def backend(name: str, namespace: dict) -> object | None:
...     return namespace.get("Renderer").draw if name == "self.backend.draw" else None
>>> FORWARD_RESOLVERS.remove(backend)

Symbol table¶

ast_harvest(source: str, tree: Module | None = None, version_branches: bool = False) → ASTSymbols[source]¶

Parse source and return its structural metadata without executing it.

Parameters:

  • source (str) – Python source text.

  • tree (ast.Module, optional) – The already parsed source, to avoid parsing it twice. Defaults to None.

  • version_branches (bool, optional) – Harvest every branch of sys.version_info / sys.platform tests, tagging definitions with their branch; by default only the branch this interpreter takes. Defaults to False.

Returns:

ASTSymbols – Harvested classes, functions, variables, type declarations and __all__. Empty but valid on SyntaxError.

See also

ASTHarvester

The visitor behind this function.

Examples

>>> syms = ast_harvest("class Foo(Bar): pass")
>>> syms.classes[0].name, syms.classes[0].bases
('Foo', ['Bar'])
>>> ast_harvest("X = TypeVar('X')").typevar_decls[0].kind
'TypeVar'
build_symbol_table(module: ModuleType | None, module_name: str, ast_symbols: ASTSymbols, all_exports: set[str] | None = None, include_private: bool = False, diagnostics: DiagnosticCollector | None = None) → SymbolTable[source]¶

Build a SymbolTable from AST metadata and, when available, the live module.

Symbols are added in this order: type aliases / TypeVars, classes (sorted by source line), functions, overload groups, variables. Classes, aliases and variables that are private or outside __all__ are held back as hidden symbols; the emitter promotes the ones a stub refers to (a TypeVar, a private base class). A name defined more than once (if/else or try/except variants) keeps its first definition. Module dunders such as __version__ and __getattr__ count as public.

Parameters:

  • module (types.ModuleType or None) – The loaded module, or None when the module was not imported (all live_* fields are then None).

  • module_name (str) – Synthetic module name, used to tell local classes from imported ones.

  • ast_symbols (ASTSymbols) – Output of ast_harvest().

  • all_exports (set of str, optional) – When given, public names outside this set are dropped. Defaults to None.

  • include_private (bool, optional) – Keep names starting with _. Defaults to False.

  • diagnostics (DiagnosticCollector, optional) – Receives notes about variables whose type cannot be determined. Defaults to None.

Returns:

SymbolTable – The populated table.

Examples

>>> from stubpy.analysis.harvest import ast_harvest
>>> table = build_symbol_table(None, "mymod", ast_harvest("class A: ...\ndef f(): ...\nX = 1"))
>>> table.all_names()
['A', 'f', 'X']

class StubContext(alias_registry: list[AliasEntry] = <factory>, type_module_imports: dict[str, str]=<factory>, used_type_imports: dict[str, str]=<factory>, config: Config = <factory>, diagnostics: DiagnosticCollector = <factory>, symbol_table: Any | None = None, all_exports: set[str] | None = None, all_order: list[str] = <factory>, star_exports: dict[str, list[str]]=<factory>, module_namespace: dict[str, ~typing.Any]=<factory>, module_name: str = '', import_map: dict[str, str]=<factory>, extra_imports: dict[str, str]=<factory>, module_loader: Any | None = None, branch_imports: list[Any] = <factory>, source_index: Any | None = None, source_module: Any | None = None, requested_names: set[str] = <factory>, submodule: str = '', submodules: list[str] = <factory>, _alias_index: dict[~typing.Any, str] | None=None, _alias_index_size: int = -1)[source]¶

Bases: object

Mutable state for stubbing one module.

Every emitter and annotation handler receives it; extensions read ctx.config and record issues in ctx.diagnostics. Every field is optional and starts empty, so StubContext() is valid.

Parameters:

  • alias_registry (list of AliasEntry) – Type aliases registered from imported sub-modules.

  • type_module_imports (dict) – Import statements for alias sub-modules, keyed by local name.

  • used_type_imports (dict) – Subset of type_module_imports actually referenced in the stub.

  • config (Config) – Per-run options.

  • diagnostics (DiagnosticCollector) – Warnings and errors from the pipeline.

  • symbol_table (SymbolTable or None) – Populated by the symbol-table stage.

  • all_exports (set of str or None) – Contents of the target module’s __all__, if any.

  • all_order (list of str) – The same names in their __all__ order, for the stub’s own __all__.

  • star_exports (dict) – For each from m import * of the module, the names it binds when m declares __all__; the stub re-exports them one by one.

  • module_namespace (dict) – __dict__ of the loaded module, used to look up forwarding targets. Empty when the module was not imported.

  • module_name (str) – __name__ of the target module (synthetic for loose scripts).

  • import_map (dict) – {local_name: import_statement} for the imports in the source.

  • extra_imports (dict) – Imports the emitters needed beyond the source’s annotations, keyed by local name (for example the class of an enum default).

  • module_loader (ModuleLoader or None) – Loader shared by a package run; None makes each run use its own.

  • branch_imports (list of ImportInfo) – Imports inside version branches; the body writes the ones it needs inside their branch instead of the header.

  • source_index (SourceIndex or None) – Harvested sources shared by a run, for back-tracing without imports.

  • source_module (SourceModule or None) – The module being stubbed in that index; variadics are resolved from it when the module was not imported (module_namespace is empty).

  • requested_names (set of str) – Names other modules of the run import from this one; they are kept in the stub even when private or outside __all__.

  • submodule (str) – For a compiled extension, the dotted path of the attribute submodule to stub ("fft" for pkg.fft); "" for the extension itself.

  • submodules (list of str) – The attribute submodules of the compiled module just stubbed, by attribute name.

Examples

>>> ctx = StubContext()
>>> ctx.diagnostics.summary()
'0 errors, 0 warnings, 0 infos'
>>> ctx.config.may_import
True
